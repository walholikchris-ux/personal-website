# 梁好 — 个人关卡策划作品集网站

## 这是什么
一个复古桌面 GUI 风格的个人网站，面向企业面试官展示关卡策划能力。模拟经典 Mac OS / Windows 95 操作系统界面。

## 如何查看
1. 双击打开 `index.html` 文件，或用浏览器打开它
2. 点击顶部菜单栏的按钮来切换不同内容窗口
3. 也可以双击桌面上的图标打开对应的窗口
4. 窗口可以拖拽移动，点击窗口标题栏拖动即可

## 如何修改内容
所有文字内容都在 `index.html` 文件中，用记事本或其他文本编辑器打开即可修改。

### 修改文字
- 打开 `index.html`
- 用 Ctrl+F 搜索你想改的文字
- 修改后保存，刷新浏览器即可看到效果

### 替换视频
- B站视频：找到 `bvid=BV12345678` 这样的文字，换成你的新BV号
- 注意有两处要改：`player.bilibili.com` 的嵌入链接 和 `www.bilibili.com/video/` 的跳转链接

### 替换照片/图片
- 把你的图片文件放到 `images/` 文件夹
- 在 `index.html` 中找到对应位置，将 `<img>` 标签的 `src` 改为你的文件名

### 修改样式
- 颜色、字体、间距等都在 `css/style.css` 中

## 文件结构
```
personal-website/
├── index.html      ← 主页面（所有内容在这里）
├── css/
│   └── style.css   ← 样式文件
├── js/
│   └── main.js     ← 窗口拖拽、菜单点击等交互
├── images/         ← 放你的图片和照片
└── README.md       ← 本文件
```

## 部署到线上
目前是本地文件，想要让别人也能访问，需要部署。推荐 GitHub Pages（免费）。部署后修改本地文件不会影响线上版本，需要重新上传。
